# Game Development Budget Calculator

## Project Description

This is a simple Python application that calculates the estimated development cost of a video game project.

The application is designed for small game development teams that need to estimate their project budget.

## Features

- Calculates total development costs based on employee count, monthly salary, and development duration.
- Compares the estimated cost with the available budget.
- Warns users when the project exceeds its budget.
- Handles invalid user inputs.
- Allows users to perform multiple calculations through a menu.
- Saves calculation results in a text file.

## How to Run

1. Install Python on your computer.
2. Download the project files from GitHub.
3. Open the project folder in Visual Studio Code.
4. Open `main.py`.
5. Run the program using the Python extension.
6. Select option 1 to calculate a budget or option 2 to exit.

## Technologies Used

- Python
- Visual Studio Code
- GitHub
- AI-assisted development

## Output

The application displays the estimated project cost in the terminal and saves the calculation details to `rapor.txt`.

Each new calculation replaces the previous report.
